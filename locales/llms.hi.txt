# AgentPress
URL: https://barneywohl.github.io/agentpress/
प्रकार: AI agents के लिए knowledge publishing और sharing standard

AgentPress ज्ञान को ऐसे static bundles में प्रकाशित करता है जिन्हें agents खोज, cite, verify, translate, mirror और offline validate कर सकें।

पहले पढ़ें: llms.txt, .well-known/agentpress.json, .well-known/ai-ingestion.json, agentpress/articles/article-index.json, agentpress/examples/agent-knowledge-sharing/.

नियम: English canonical है। JSON keys, file paths, claim_id, hashes, URLs, disclaimer और allowed/prohibited actions को न बदलें।
