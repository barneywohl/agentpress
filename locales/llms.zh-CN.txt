# AgentPress
URL: https://barneywohl.github.io/agentpress/
类型: 面向 AI Agent 的发布与知识共享标准

AgentPress 让人和组织把知识发布成 Agent 可读取、可引用、可验证、可翻译、可离线打包的静态资料包。

Agent 应先读取: llms.txt, .well-known/agentpress.json, .well-known/ai-ingestion.json, agentpress/articles/article-index.json, agentpress/examples/agent-knowledge-sharing/.

用途: 发布知识、建立来源地图、定义允许操作、标记新鲜度、提供镜像/回退 URL、支持 CLI 验证。

规则: 英文为权威版本。保留 JSON 键、文件路径、claim_id、哈希、URL、免责声明和安全边界。
