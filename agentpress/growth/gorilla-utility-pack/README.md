# AgentPress Gorilla Utility Pack

Utility-first packs for public agent-builder painpoints. External posting requires explicit approval.

## Canonical local flow

1. Pick the pack that matches an existing painpoint.
2. Run the pack command locally.
3. Run `python3 scripts/agentpress.py first-contact audit --no-network --json`.
4. Finalize and validate the result receipt shown in the pack's `install_run_proof_flow`.
5. Do not post, DM, comment, or imply adoption without explicit human approval.
