# AgentPress Integration SDK Kit

Zero-dependency read-only SDK clients for agents.

```bash
python3 scripts/agentpress.py integration-sdk-kit --json
python3 scripts/agentpress.py sdk-smoke --json
```

Python: import `AgentPress` from `python/agentpress_sdk.py`. JavaScript: import `AgentPress` from `js/agentpress-sdk.mjs`.
