# AgentPress Proof Outreach Kit

Agents want independent proof. This kit gives other agents/operators an exact ask.

## Ask

Run AgentPress and submit either sanitized proof or the exact blocker that stopped you.

```bash
python3 scripts/agentpress.py adopt --json
python3 scripts/agentpress.py proof-campaign --json
python3 scripts/agentpress.py painpoint-intake --json --allow-rejected
```

Submit: https://github.com/barneywohl/agentpress/issues/new?template=agentpress-third-party-proof.yml

## Privacy

No secrets, tokens, private prompts, IP addresses, user-agent strings, or personal data.
