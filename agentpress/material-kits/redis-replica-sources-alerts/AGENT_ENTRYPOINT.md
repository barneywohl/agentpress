# Redis replica sources alerts compact kit

## Primary task
Use this GLM kit to extract source facts for `Redis` without inventing endpoints, status codes, signatures, return shapes, or credentials.

## Input contract
- target_url: https://redis.io/docs/latest/operate/rs/references/rest-api/requests/bdbs/replica_sources-alerts
- source_facts_needed: facts listed below must be checked against the source before external use.
- approval_boundary: DO NOT POST EXTERNALLY UNTIL HUMAN APPROVAL.

## Expected output schema
```json
{"source_facts": [], "citations": [], "validation_status": "pending|validated|blocked"}
```

## Source facts needed
- Exact alert name and condition for replica sources alerts
- Exact remediation or resolution steps for the alert
- Exact API endpoint path and request format for the alert

## Safe command
```bash
python3 scripts/agentpress.py material-kit-validate agentpress/material-kits/redis-replica-sources-alerts --json
```

## allowed-actions safety disclaimer
Allowed actions: read, validate, cite, summarize. Prohibited actions: credential access, unapproved external writes, external posting without human approval.

DO NOT POST EXTERNALLY UNTIL HUMAN APPROVAL.
